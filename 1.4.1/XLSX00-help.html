Export SQL/file to Excel XLSX (XLSX00)

Where allowed to run: All environments (*ALL)
Threadsafe: No 		Parameters
Examples
Error messages

The Export to Excel XLSX (XLSX00) command writes the result of an SQL SELECT statement, or the records of a database file or member, to a Microsoft Excel workbook (.xlsx, Office Open XML) in a stream file of the integrated file system.

The workbook is created by an ILE RPG program (XLSX00R) without Java, PASE or other products. Numbers stay numeric, dates, times and timestamps become real Excel dates, text is written as Unicode (UTF-8) converted from the CCSID of each column, and NULL values become empty cells.

A new workbook can be created, a sheet can be added to an existing workbook, the content of a sheet can be replaced, or rows can be appended at the bottom of an existing sheet, also in workbooks created by Excel or other programs.

The written cells can get a workbook name or become an Excel table, and the sheet can be hidden, so that report sheets, charts and pivot tables of a template can use the data.

The header row can show the column names, the column headings or the column text, and the column text can also be added as a second header row or as Excel notes on the headings.

Version 1.4.1.

Restrictions:

  • A worksheet holds at most 1,048,576 rows (header included) and 16,384 columns. Rows beyond the limit are not written and the completion message says that the sheet was truncated. The command handles at most 1000 columns.

  • Text longer than 32,767 bytes is cut. BLOB, ROWID and DATALINK columns are left empty. CLOB, DBCLOB and XML columns are read up to 32,740 bytes.

  • The workbook must be smaller than 4 GB (no ZIP64). When an existing workbook is updated, its parts styles.xml, workbook.xml and [Content_Types].xml must each be smaller than 1 MB.

  • The file is written as a temporary file with the suffix .tmp and renamed at the end, so an existing workbook is not damaged by a failing run. You need *RWX authority to the directory of the stream file.

  • The program XLSX00R is called with the library list of the job.

SQL statement or file (SRC)

Specifies what is exported. This is a required parameter.

select-statement
An SQL statement that starts with SELECT, WITH or VALUES. System naming is used: unqualified tables are found through the library list, and both LIB/TABLE and LIB.TABLE are accepted. Numeric literals use the period as decimal separator. Column names or AS clauses become the default headings.
library-name/file-name
A database file, table or view, as library/file, library.file or file alone (the file is then found through the library list). A member is given in parentheses, for example MYLIB/MYFILE(MBR2); the member is read through the alias QTEMP/XLSX00A.

To stream file (TOSTMF)

Specifies the path of the workbook, for example /home/user/orders.xlsx. This is a required parameter.

With MODE(*REPLACE) an existing file is replaced. With MODE(*ADDSHEET) or MODE(*APPEND) a file that does not exist is created as a new workbook.

Mode (MODE)

Specifies how the stream file is written.

*REPLACE
A new workbook with one sheet is created. An existing file is replaced.
*ADDSHEET
A new sheet is added at the end of an existing workbook. When the sheet name is already used, a number is added, for example Data (2).
*APPEND
The rows are added after the last row of the sheet named in the SHEET parameter, or of the last sheet when SHEET(*DFT) is specified. No header is written unless the sheet is empty; an autofilter of the sheet is extended to the new rows. When the sheet does not exist, it is added as with *ADDSHEET.
*REPLSHEET
The content of the sheet named in the SHEET parameter is replaced; with SHEET(*DFT) the file or member name, or Sheet1, is used. The sheet keeps its name and position; the other sheets, with their formulas, charts and pivot tables, are kept unchanged and still refer to the sheet by name. Excel recalculates all formulas when the workbook is opened. Notes, drawings and tables that were on the replaced sheet itself are dropped. Pivot tables based on a fixed cell range do not grow with the new rows: base them on a whole-column range or a dynamic name, and set their option to refresh data when the file is opened. When the sheet does not exist, it is added as with *ADDSHEET.

Sheet name (SHEET)

Specifies the name of the worksheet (up to 31 characters). The characters [ ] : * ? / \ are replaced by an underscore.

*DFT
The file or member name is used when a file is exported, otherwise Sheet1. With MODE(*APPEND) the last sheet of the workbook is used. With MODE(*REPLSHEET) the sheet with this default name is replaced.
sheet-name
Specify the name of the sheet.
Top

Header row (HEADER)

Specifies the content of the header row. The header row is bold on a blue band; with FILTER(*YES) it has an autofilter and with FREEZE(*YES) it stays visible when scrolling.

*LABELS
The column headings (LABEL ON COLUMN ... IS, the three lines of 20 characters joined), or the column name when a column has no heading.
*TEXT
The column text (LABEL ON COLUMN ... TEXT IS, field text of DDS files), or the heading, or the name, in this order. The text is taken from the base column of each result column, also through joins, views and AS names; expressions use their name.
*NAMES
The column names (or AS names) of the result.
*NONE
No header row is written. The parameters HDRTEXT, FILTER, FREEZE and COLDESC are ignored.
Top

Column headings (HDRTEXT)

Specifies your own headings, separated by semicolons, in the order of the columns. An empty item keeps the heading chosen with the HEADER parameter. Example: 'Customer;Name;;Balance' changes the headings of columns 1, 2 and 4.

*NONE
The headings are chosen with the HEADER parameter.
heading-list
Specify up to 5000 characters.

Autofilter on header row (FILTER)

Specifies whether the header row gets the Excel autofilter buttons.

*YES
An autofilter is set on the header row (on the second header row when COLDESC(*ROW) or COLDESC(*BOTH) is specified).
*NO
No autofilter.
Top

Freeze header row (FREEZE)

Specifies whether the header rows stay visible when the sheet is scrolled.

*YES
The header rows are frozen.
*NO
The header rows scroll with the data.
Top

Compression level (LEVEL)

Specifies how much effort is spent compressing the workbook. Higher levels give smaller files and take more time.

2
Good balance of speed and size, recommended for most exports.
0
No compression. Fastest, but the file is 5 to 7 times larger.
1-9
Levels 1 to 4 compare each position once (fast). Levels 5 to 9 also try the next position for a longer match, as zlib does, and give smaller files. Measured on 200,000 rows by 10 columns (91 MB of sheet data):

  • Level 2: 15.1 MB in 6 seconds.

  • Level 4: 12.3 MB in 11 seconds.

  • Level 6: 11.3 MB in 15 seconds.

  • Level 7: 10.8 MB in 19 seconds.

  • Level 9: about as small as level 7, in 33 seconds.

Column text: row / notes (COLDESC)

Specifies whether the column text (LABEL ON COLUMN ... TEXT IS, field text of DDS files) is added to the header. The text is taken from the base column of each result column. This parameter is ignored with HEADER(*NONE).

*NONE
No column text is added.
*ROW
A second header row shows the column text, in italics. When the heading already is the text (HEADER(*TEXT)), the second row shows the column name.
*NOTE
Each heading gets an Excel note, shown when the mouse is over the cell, with the base column (schema.table.column), the SQL data type, the column text and the column heading. Notes are added only to sheets created by the command, not when rows are appended to an existing sheet.
*BOTH
Both a second header row and notes.
Top

Defined name over the data (RANGENAME)

Specifies a workbook name (Formulas, Name Manager in Excel) for the cells written by the command: the header row and the data rows, for example Sales = 'Data'!$A$1:$K$13. Formulas, charts and pivot tables can use the name instead of a cell range. An existing workbook name with the same name is replaced; with MODE(*APPEND) only its last row is moved to the new last row.

*NONE
No name is defined.
name
Up to 255 characters: letters A-Z, digits, _ . and \, starting with a letter, _ or \. A name that looks like a cell reference (for example AB12 or R1C1) is not allowed. Put the name between apostrophes to keep lower case letters.
Top

Excel table (TABLE)

Specifies whether the header row and the data rows of a sheet created by the command become an Excel table (Insert, Table in Excel). A table has its own filter buttons and banded rows, and formulas, charts and pivot tables that refer to the table name follow its size when rows are added.

With MODE(*APPEND), tables of the existing sheet that end at its last row are extended over the new rows; this parameter is then ignored. With MODE(*REPLSHEET) the tables of the replaced sheet are removed first, so a table with the same name can be created again: pivot tables, charts and formulas of a report template that use the table name keep working with the new number of rows.

A table needs exactly one header row: it cannot be used with HEADER(*NONE) or with COLDESC(*ROW) or COLDESC(*BOTH). Duplicate headings get a number (Name, Name2).

*NONE
No table; the header row gets a normal autofilter (FILTER parameter).
*YES
A table named after the sheet, for example sheet Data gives table Data. Characters that are not allowed become underscores, and a number is added when the name is already used.
table-name
The name of the table, with the same rules as for RANGENAME. It must not be used by another table or workbook name.
Top

Hide the sheet (HIDE)

Specifies whether the sheet written by the command is hidden, for example a data sheet used by the report sheets of a template. A workbook must keep at least one visible sheet.

*DFT
A new sheet is visible. An existing sheet (MODE(*APPEND) or MODE(*REPLSHEET)) keeps its state, so a hidden data sheet stays hidden.
*NO
The sheet is visible.
*YES
The sheet is hidden. It can be shown again with Unhide in Excel.
*VERY
The sheet is very hidden: it is not listed by Unhide in Excel and can only be shown again with VBA or by a program.

Examples for XLSX00

Example 1: Export a query 

XLSX00 SRC('select * from mylib/orders where year = 2026')
       TOSTMF('/home/user/orders.xlsx')

Creates orders.xlsx with one sheet, column headings in the header row, autofilter and frozen header.

Example 2: Add a file as a new sheet, with column text 

XLSX00 SRC('MYLIB/CUSTOMERS') TOSTMF('/home/user/orders.xlsx')
       MODE(*ADDSHEET) SHEET(Customers) HEADER(*TEXT) COLDESC(*NOTE)

Adds the sheet Customers to orders.xlsx. The headings are the field texts; each heading has a note with the field name, type and text.

Example 3: Append the rows of a member to a sheet 

XLSX00 SRC('MYLIB/DAILY(D20261028)') TOSTMF('/home/user/log.xlsx')
       MODE(*APPEND) SHEET(Daily)

Adds the records of member D20261028 after the last row of sheet Daily.

Example 4: Refresh the data sheet of a report template 

XLSX00 SRC('select * from mylib/sales where year = 2026')
       TOSTMF('/reports/sales.xlsx') MODE(*REPLSHEET) SHEET(Data)

Rewrites sheet Data of sales.xlsx. The summary sheets, charts and pivot tables that use Data are kept and show the new figures when the workbook is opened.

Example 5: Hidden data table for a report template 

XLSX00 SRC('select * from mylib/sales') TOSTMF('/reports/sales.xlsx')
       MODE(*REPLSHEET) SHEET(Data) TABLE(Sales) HIDE(*YES)

Rewrites the hidden sheet Data as table Sales. Pivot tables and charts of the template based on Sales show all the new rows.

Example 6: Call from RPG 

/copy '/home/user/xlsx/XLSX00PR.rpgleinc'
XLSX00R(sql : '/home/user/x.xlsx' : '*REPLACE' : 'Data' : '*TEXT'
        : *omit : '*YES' : '*YES' : 2 : '*NOTE' : rows : msg
        : 'SalesRange' : '*YES' : '*DFT');

With the optional parameter msg, errors are returned in msg (blank when the export succeeded) instead of an escape message; rows receives the number of rows written.

Error messages for XLSX00

*ESCAPE messages

CPF9898
The export failed. The text starts with XLSX00R and tells the reason, for example an SQL error with its SQLSTATE, a stream file that cannot be written, or a workbook that cannot be updated.

*COMP messages

CPF9897
Number of rows written, sheet, stream file and elapsed seconds.
