Import Excel XLSX to table (XLSX01)

Where allowed to run: All environments (*ALL)
Threadsafe: No 		Parameters
Examples
Error messages

The Import Excel XLSX to table (XLSX01) command reads the rows of a worksheet of a Microsoft Excel workbook (.xlsx, Office Open XML) from a stream file of the integrated file system and inserts them into a Db2 table. The table can be created by the command or can already exist.

The workbook is read by an ILE RPG program (XLSX10R) without Java, PASE, ODBC or a PC. Workbooks written by Excel, LibreOffice, Google Sheets, openpyxl, XlsxWriter and the XLSX00 command can be read.

With the default values the command finds the data by itself:

  • The first Excel table of the sheet, or the range of an active autofilter, is used when there is one.

  • Otherwise title rows above the data (rows with few filled cells) are skipped and the data ends at the last filled row. Empty rows inside the data are ignored.

  • The first row is used as header when it holds only distinct texts over numbers or dates, or texts that do not repeat in the data.

  • When the table is created, the type of each column is chosen from all the values of the column: INTEGER, BIGINT, DECIMAL, DOUBLE, DATE, TIME, TIMESTAMP, SMALLINT for TRUE/FALSE, and VARCHAR for text. Column names come from the headings (or COL_A, COL_B...), with the heading as column text and column heading.

  • When the table exists, the Excel columns are matched to the table columns by heading (column name, system name, text or column heading) or else by position, and every value is converted to the column type.

With ERRORS(*STOP), the default, all values are checked before the first row is inserted: if one does not fit, nothing is written and the messages tell the cell, the value and the reason.

Version 1.4.1.

Restrictions:

  • At most 1000 columns are read. Formulas are read as their last calculated value, which Excel stores in the file. Cells with an Excel error (#N/A, #DIV/0! ...) are read as empty cells.

  • The .xlsb, .xls and .ods formats and password protected (encrypted) workbooks are not supported; save them as .xlsx first.

  • The rows are inserted without commitment control, in blocks of up to 1000 rows. With ERRORS(*SKIP) or ERRORS(*NULL) the rows inserted before an unexpected database error stay in the table.

  • Text that is longer than 32,740 bytes in UTF-8 is cut.

From stream file (FROMSTMF)

Specifies the path of the workbook, for example /home/user/orders.xlsx. This is a required parameter.

Top

To table (TOFILE)

Specifies the table that receives the rows. This is a required parameter.

table-name
The system name of the table or physical file. When it does not exist and CRTFILE(*YES) is specified, it is created.
*NONE
Nothing is written to the database. The workbook is analysed and the result (sheets, data area, header, column types and the CREATE TABLE statement that would be used) is written to the REPORT stream file and to the job log.

The possible library values are:

*LIBL
The library list is searched; a new table is created in the current library.
*CURLIB
The current library of the job.
library-name
The library of the table.
Top

Sheet name or number (SHEET)

Specifies the worksheet to read.

*FIRST
The first visible worksheet of the workbook.
sheet-name
The name of the sheet, as shown on its tab. Uppercase and lowercase letters are not distinguished.
sheet-number
The position of the sheet in the workbook, 1 for the first one, hidden sheets included.
Top

Cell range, table or name (RANGE)

Specifies the cells to read.

*AUTO
The first Excel table of the sheet, else the range of the autofilter of the sheet (with the rows added below it), else the filled cells found by the heuristic described in the command help.
cell-range
A range like B4:H200, whole columns like B:H, or the top left cell like B4 (the data then goes on to the last filled row and column). The first row of the range is the header row when there is one.
table-name
The name of an Excel table (Insert > Table) of any sheet. Its header row and totals row are handled automatically.
defined-name
A workbook defined name (Formulas > Name Manager) that refers to a cell range.
Top

Header row (HEADER)

Specifies whether the first row of the data area holds column headings.

*AUTO
Decided from the cells: a row of distinct texts over numbers, dates or texts that differ from it is a header row.
*YES
The first row holds the headings. They are used to name new columns and to match existing columns.
*NO
The first row is data. New columns are named COL_A, COL_B ... after the Excel column letters, and existing columns are matched by position.
*SKIP
The first row is a header, but it is not used: the row is skipped and columns are named and matched as with *NO.
Top

First row (STARTROW)

Specifies the sheet row where the data area starts (the header row when there is one). Rows above it are ignored, for example report titles.

*AUTO
The first row of RANGE, or the first row found by the heuristic.
row-number
A row number from 1 to 1048576, as shown by Excel.
Top

Rows to read (ROWSEL)

*ALL
All the rows of the data area are read.
*VISIBLE
Rows hidden by an Excel filter, or hidden by hand, are skipped. Use it to import only what the user filtered in Excel. The filter must have been applied by Excel before the file was saved.
Top

Maximum rows (MAXROWS)

Specifies the maximum number of data rows to insert.

*ALL
All the rows are inserted.
number
Only the first rows are inserted, for example to try a big file.
Top

Replace or add rows (MBROPT)

*ADD
The rows are added to the rows already in the table.
*REPLACE
The rows of an existing table are deleted (TRUNCATE, or DELETE when truncate is not allowed) after all the values have been checked and before the new rows are inserted.
Top

Create table (CRTFILE)

*YES
A table that does not exist is created with the columns and types found in the sheet. An existing table is used as it is.
*NO
The table must exist.
*REPLACE
An existing table is dropped and created again from the sheet. Use it for work tables only: indexes, views, authorities and triggers over the old table are lost.
Top

Column mapping (MAP)

Specifies how the Excel columns are matched to the columns of an existing table.

*AUTO
By heading when at least one heading matches a column, else by position.
*NAME
By heading only. A heading matches the column name, the system column name, the column text or the column heading, ignoring case, blanks and punctuation. Excel columns without a match are ignored and reported.
*POS
The first Excel column goes to the first table column and so on. Identity columns and columns generated always are skipped.

Table columns without an Excel column receive their default value. A NOT NULL column without default that gets no value stops the command.

Top

Column map (COLMAP)

Specifies explicit pairs Excel column = table column, separated by semicolons. The Excel column is given by its heading or by its letter. *SKIP as table column ignores the Excel column. Pairs not given follow the MAP parameter. 

COLMAP('Customer no.=CUSNUM; Amount EUR=AMOUNT; F=*SKIP')

For a new table, COLMAP gives the names of the new columns.

Top

Column types (TYPES)

Specifies the SQL type of columns of a new table, instead of the type found from the values. Pairs column=type are separated by semicolons; the column is given by its new name, its heading or its Excel letter. 

TYPES('ZIP=CHAR(5); AMOUNT=DECIMAL(11,2); C=VARCHAR(200)')

With TYPES the values are checked like for an existing table.

Top

Nullable new columns (NULLS)

*NO
New columns are NOT NULL WITH DEFAULT: empty cells become blanks, zero, 0001-01-01 for dates or 00.00.00 for times.
*YES
New columns allow null values: empty cells become NULL.
Top

Values that do not fit (ERRORS)

Specifies what happens with a value that cannot be converted to its column, for example a text in a numeric column, a number with too many digits or a text that is too long.

*STOP
All the values are checked before anything is written. When one value does not fit, no row is inserted, a new table is dropped, and the first 20 errors are sent as diagnostic messages.
*SKIP
Rows with a value that does not fit are not inserted. The other rows are.
*NULL
A value that does not fit becomes NULL, or the default value when the column does not allow null values. Text that is too long is cut.
Top

CCSID of new text columns (STRCCSID)

*AUTO
Text columns get the CCSID of the job, unless a value has characters the job CCSID cannot hold (Greek, Cyrillic, Chinese ...): then the column is VARCHAR CCSID 1208 (UTF-8).
*JOB
The CCSID of the job for all text columns. Characters that it cannot hold are replaced by the substitution character.
*UTF8
VARCHAR CCSID 1208 for all text columns.
*UTF16
VARGRAPHIC CCSID 1200 for all text columns.
ccsid
A single-byte CCSID such as 37, 280 or 1144.
Top

Trim blanks of text (TRIM)

*YES
Leading and trailing blanks of text cells are removed.
*NO
Texts are kept as they are.
Top

Order of text dates (DATFMT)

Specifies how dates written as text, like 03/04/2026, are read. Real Excel dates and ISO texts like 2026-04-03 are always read correctly.

*DMY
Day, month, year (03/04/2026 is 3 April).
*MDY
Month, day, year (03/04/2026 is 4 March).
*YMD
Year, month, day.
Top

Report stream file (REPORT)

Specifies a stream file that receives a UTF-8 text report: sheets of the workbook, data area and how it was found, header decision, each column with its type, mapping and statistics, the SQL statements, errors and timings.

*NONE
No report is written.
path-name
The path of the report; an existing file is replaced.

Examples for XLSX01

Example 1: Create a table from a workbook 

XLSX01 FROMSTMF('/home/user/prices.xlsx') TOFILE(MYLIB/PRICES)

Creates table PRICES from the first sheet, with names and types found from the data.

Example 2: Refresh an existing table 

XLSX01 FROMSTMF('/home/user/rates.xlsx') TOFILE(MYLIB/RATES)
       SHEET('2026') MBROPT(*REPLACE) CRTFILE(*NO)

Checks all the values of sheet 2026, then replaces the rows of RATES.

Example 3: Only the filtered rows of a report 

XLSX01 FROMSTMF('/home/user/open.xlsx') TOFILE(QTEMP/OPEN)
       STARTROW(4) ROWSEL(*VISIBLE)

Example 4: Analyse only 

XLSX01 FROMSTMF('/home/user/x.xlsx') TOFILE(*NONE)
       REPORT('/home/user/x.txt')

Example 5: Call from RPG 

/copy '/home/user/xlsx/XLSX10PR.rpgleinc'
XLSX10R('/home/user/x.xlsx' : 'ORDERS    MYLIB     ' : rows : msg
       : 'Data' : *omit : '*YES');

With the parameter msg, errors are returned in msg (blank when the import succeeded) instead of an escape message; rows receives the number of rows inserted.

Error messages for XLSX01

*ESCAPE messages

CPF9898
The import failed. The text starts with XLSX10R and tells the reason, for example a file that is not a workbook, a sheet that does not exist, values that do not fit (see the diagnostic messages before it) or an SQL error with its SQLSTATE.

*DIAG messages

CPF9897
One message for each of the first 20 values that do not fit: cell, value, column and reason.

*COMP messages

CPF9897
Rows inserted, sheet, table and elapsed seconds.
